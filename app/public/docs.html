API do Losambo

Uma API pequena por cima do WAHA. Cada endpoint Losambo faz uma ou mais chamadas WAHA por si e acrescenta contas, OTP, limites e faturação.

POST

/v1/otp/send

Gera um código de 6 dígitos, confirma que o número tem WhatsApp, mostra “a escrever…” e envia. O código fica guardado só como hash e expira em 5 minutos.

Corpo do pedido

to obrigatório
Número em formato internacional, ex. +2449XXXXXXXX.
app
Nome mostrado na mensagem.
via
Número a usar. Sem valor, o Losambo escolhe o número com mais quota livre.
fallback
"reverse" devolve um link de verificação inversa se o número estiver limitado.

Erros

404 not_on_whatsapp — o destinatário não tem WhatsApp.

409 number_not_working — o número está desligado (estado diferente de WORKING).

429 number_capped — quota de novas conversas esgotada (CAPPED).

402 subscription_inactive — a subscrição da conta não está ativa; toda a API fica desativada.

JavacurlNode 
var res = losambo.otp().send(
  OtpSend.builder()
    .to("+2449XXXXXXXX")
    .app("MinhaLoja")
    .fallback("reverse")

Sequência no WAHA

  1. GET /api/contacts/check-exists
  2. GET /api/sessions/{s}/capping
  3. POST /api/startTyping
  4. POST /api/sendText
  5. POST /api/stopTyping

Eventos de webhook

Repassamos os eventos do WAHA com a mesma forma e acrescentamos eventos próprios do Losambo.

message

Mensagem recebida.

message.ack

Enviada, entregue ou lida.

session.status

WORKING, SCAN_QR_CODE, FAILED…

otp.verified

Código confirmado (envio ou inverso).

number.capping

Número chegou a um aviso de quota.
